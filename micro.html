Architecture of 8086

The 8086 is a 16-bit microprocessor that accesses up to 1MB of memory via a 20-bit address bus.

Two Main Units

  • BIU (Bus Interface Unit): Handles all data and addresses on the buses. Fetches instructions, reads/writes data to memory and I/O.
  • EU (Execution Unit): Tells the BIU where to fetch instructions or data from. Decodes and executes instructions.

Registers (16-bit)

  • General Purpose: AX (Accumulator), BX (Base), CX (Count), DX (Data)
  • Segment: CS (Code), DS (Data), SS (Stack), ES (Extra)
  • Pointer & Index: SP (Stack Pointer), BP (Base Pointer), SI (Source Index), DI (Destination Index)

Pin Diagram

The 8086 is a 40-pin Dual Inline Package (DIP) IC. It operates in two modes based on the MN/MX pin.

Pin Categories

  • Address/Data (AD0–AD15): Time-multiplexed pins carrying either address or data.
  • Address/Status (A16/S3–A19/S6): Upper 4 bits of the 20-bit address.
  • Control Signals: RD (Read), WR (Write), ALE (Address Latch Enable).
  • Power: Vcc (+5V, Pin 40), GND (Pins 1 & 20).

Operating Modes

  • Minimum Mode (Pin 33 High): The 8086 operates as a single processor in the system. It generates all control signals itself.
  • Maximum Mode (Pin 33 Low): Used in multiprocessor systems (e.g., with 8087 coprocessor). An external bus controller (8288) generates control signals.

Instruction Set

The instructions used by the 8086 can be grouped into several key functional categories.

Data Transfer

Moves data between registers, or between memory and registers.

MOV AX, BX // Copies BX to AX
PUSH CX // Pushes CX to stack
POP DX // Pops stack top to DX

Arithmetic

Performs basic math operations.

ADD AL, 05H // AL = AL + 05H
SUB CX, BX // CX = CX - BX
MUL BL // AX = AL * BL

Logical

Bitwise operations and shifting.

AND AX, 0FFFH // Bitwise AND
XOR BX, BX // Clears BX (BX=0)
NOT CX // 1's complement of CX

Control Transfer

Alters the flow of program execution.

JMP 2000H // Unconditional jump
CALL 3000H // Call subroutine
RET // Return from subroutine

Addressing Modes

Addressing modes define how the microprocessor finds the data required for an instruction.

Immediate & Register

  • Immediate: The 8-bit or 16-bit data is specified directly in the instruction.
    MOV AX, 1234H
  • Register: The operand is contained in an 8-bit or 16-bit register.
    MOV AX, BX

Direct & Indirect

  • Direct: The effective address of the memory location is given directly.
    MOV AX, [5000H]
  • Register Indirect: The effective address is stored in a pointer/index register (BX, DI, SI).
    MOV AX, [BX]

Indexed & Based

  • Indexed: Operand's address is the sum of an index register (SI/DI) and an 8/16-bit displacement.
    MOV AX, [SI + 20H]
  • Based: Operand's address is the sum of a base register (BX/BP) and a displacement.
    MOV AX, [BX + 04H]
