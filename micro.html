Unit I

8086 Architecture

Evolution of microprocessors, 8086 salient features, pin descriptions, internal architecture, register organisation, pipelining, and memory segmentation.

Salient Features of 8086

Data Bus

16-bit data bus — transfers 2 bytes per memory cycle, doubling throughput over 8-bit predecessors.

Address Bus

20-bit address bus provides access to 2²⁰ = 1 MB of physical memory (locations 00000H–FFFFFH).

Clock & Power

Single-phase clock with 33% duty cycle. Operates at +5V, housed in 40-pin DIP package.

Pipelining

Two-stage pipeline — Fetch Stage pre-fetches up to 6 bytes into queue; Execute Stage runs concurrently.

Registers

14 internal 16-bit registers including data, pointer, index, segment registers, IP, and flags.

I/O Ports

Supports up to 64K I/O ports with multiplexed address/data bus (AD0–AD15, A16–A19).

⚡
Important: The 8086 uses a multiplexed address/data bus — AD0–AD15 carry addresses during T1 and data during T2–T4 of each bus cycle. A16–A19 carry the upper 4 address bits and status signals.

Internal Architecture — BIU & EU

The 8086 is internally divided into two independent functional units that operate asynchronously — forming its pipelined architecture.

Bus Interface Unit (BIU)

  • Provides 16-bit bidirectional data bus and 20-bit address bus
  • Responsible for instruction fetching, queuing, operand fetch/store
  • Contains a 6-byte instruction prefetch queue (FIFO)
  • Generates 20-bit physical addresses using segment + offset
  • Contains: Segment registers, IP, Address adder, Queue
  • Fetches 2 bytes per bus cycle using 16-bit data bus

Execution Unit (EU)

  • Decodes and executes instructions from queue
  • Reads instructions from BIU queue — never accesses bus directly
  • Contains: ALU, Control circuitry, Flag register, Instruction decoder
  • Also contains: General purpose, pointer, and index registers
  • Tests and updates status/control flags after each instruction
  • Requests BIU to read/write operands from memory or I/O
💡
Remember: When the EU executes a branch/jump instruction, the BIU automatically flushes the queue and refills it from the new address. This is the only scenario that disrupts the pipeline.

Memory Segmentation & Physical Address Generation

Physical Address Formula
Physical Address = Segment Register × 10H + Offset
Example: CS = 1000H, IP = 0200H
PA = 1000H × 10H + 0200H = 10000H + 0200H = 10200H
⚠️
Common Mistake: Multiplying by 10H means appending one hex zero (shifting left by 4 bits), NOT multiplying by 10 decimal. CS=1000H → 10000H (not 10000 decimal).

Segment:Offset Notation

Each memory location accessed as Segment:Offset. The 20-bit physical address allows 1MB total, but each segment is 64KB (16-bit offset).

Default segment registers: CS for code, DS for data, SS for stack (BP/SP), ES for string destinations.

Segment Overlap

Two segments can overlap or even point to the same memory area. A 64KB segment can start at any 16-byte boundary (paragraph boundary).

Maximum physical address space: FFFFF H = 1,048,575 bytes = 1 MB.

Unit II

Instruction Set of 8086

Addressing modes, data transfer, arithmetic, logical, bit manipulation, string, and branch instructions with examples.

Addressing Modes

Addressing modes define how an operand is specified in an instruction. 8086 supports 8 data addressing modes.

1. Immediate Addressing Mode

Operand is part of the instruction itself. Can only be a source operand.

Assembly
MOV AX, 2500H    ; Load 2500H into AX
MOV BL, 0FFH    ; Load FFH into BL
2. Register Addressing Mode

Operands are registers. Fastest mode — no memory access required. Both operands must be the same size.

Assembly
MOV AX, BX    ; Copy BX to AX
MOV DL, AL    ; Copy AL to DL
MOV SI, DX    ; Copy DX to SI
3. Direct Addressing Mode

16-bit memory address specified directly in instruction (in square brackets). Default segment is DS.

Assembly
MOV BL, [2000H]    ; Load from DS:2000H into BL
MOV AX, ES:[4321H] ; Load from ES:4321H (segment override)
4. Register Indirect / Base / Index / Based-Indexed Modes
ModeFormulaExample

Base Addressing[BX/BP ± disp]MOV AL, [BX+15]
Index Addressing[SI/DI ± disp]MOV AL, [SI+10]
Based Indexed[BX/BP + SI/DI]MOV AL, [BX+SI]

Assembly Language Programming

Introduction to ALP, assembler directives, memory models, and sample programs for arithmetic operations.

ALP Basics — Tools in the Chain

Editor

Writes the source file (.ASM). Contains mnemonics, labels, and comments in symbolic form.

Assembler

Translates .ASM → object file (.OBJ) containing machine instructions and binary data.

Linker

Combines multiple .OBJ files + libraries → executable (.EXE) with resolved addresses.

Loader

Loads executable into RAM at a specific address; adjusts all absolute addresses accordingly.

Debugger

Executes program with breakpoints; monitors register and memory state for troubleshooting.

Unit IV

Advanced Processors

Introduction to Pentium processor, architecture, pipelining, Pentium Pro, and classification of advanced processors.

Pentium Processor — Key Features

Package & Technology

5th generation (P5, 1993). 273-pin PGA package. BiCMOS technology (BJT + CMOS). 0.8μm fabrication.

Bus Architecture

64-bit data bus and 32-bit address bus. Supports 4GB physical memory. 8-level memory banking for byte addressing.

Superscalar

Two integer units (U-pipe, V-pipe) + one 64-bit FPU. Can execute 2 instructions per clock cycle. 5-stage integer pipeline; 8-stage FP pipeline.

Cache Memory

On-chip L1 cache split into 8KB instruction cache + 8KB data cache. Eliminates off-chip cache bus delay.

Branch Prediction

Branch Target Buffer (BTB) with 256 entries, 4-way set associative. 95% branch prediction accuracy, preventing pipeline flushes.

Virtual Memory

Supports 64TB virtual memory using segmentation + paging. Even parity checking ensures data integrity.

Pentium Pro Architecture — 3 Main Units

Fetch/Decode Unit

Receives instructions from instruction cache. Decodes them into a series of micro-operations (µops) — the fundamental unit of Pentium Pro execution.

Dispatch/Execute Unit

Accepts µops from the instruction pool. Schedules execution based on data dependencies and resource availability. Supports out-of-order execution.

Retire Unit

Commits temporary results to permanent architectural state in original program order. Checks completion and resolves speculative results.

Practice Questions

MCQs, short answers, and long-answer questions for exam preparation.

Multiple Choice Questions

1. What is the size of the instruction prefetch queue in 8086?
The BIU contains a 6-byte FIFO instruction queue that allows prefetching of up to 6 instruction bytes ahead.
2. The MN/M̅X̅ pin of 8086 selects the operating mode. Minimum mode is selected when this pin is:
Logic HIGH (1) on MN/M̅X̅ selects Minimum mode (single processor). Logic LOW (0) selects Maximum mode (multiprocessor).
3. Which register is used as the default count register in LOOP instruction?
CX (Counter register) is the dedicated loop counter. LOOP decrements CX and jumps if CX ≠ 0.
4. In 8086, physical address is generated as:
Multiplying by 10H (hex) = shifting left by 4 bits. E.g., CS=1000H → 10000H, then add IP offset.

Short Answer Questions

Q: What is pipelining in 8086? How does BIU and EU achieve it?

Pipelining is an overlapping technique where instruction fetch and execution occur simultaneously. In 8086, the BIU (Bus Interface Unit) prefetches up to 6 bytes of instructions into the queue while the EU (Execution Unit) executes the current instruction. This overlap improves CPU utilization and system performance. The pipeline is disrupted only when a branch/jump instruction is executed — the BIU flushes the queue and starts fetching from the new address.

Q: Explain memory segmentation in 8086.

8086 uses a segmented memory model to access its 1MB physical address space using 16-bit registers. Memory is divided into logical segments, each up to 64KB (16-bit offset). The physical address is calculated as: Physical Address = Segment × 10H + Offset. Four segment registers (CS, DS, SS, ES) hold the base address of code, data, stack, and extra segments respectively. This allows programs to be written in a position-independent manner and enables multiple programs to share memory safely.

Q

What is the maximum physical memory that 8086 can address?

A

1 MB (2²⁰ = 1,048,576 bytes)
Because of the 20-bit address bus (A0–A19).

Q

What does BHE̅ pin do in 8086?

A

Bus High Enable — when LOW, enables the upper data byte (D8–D15) on the data bus for odd-byte access.

Q

What is the difference between ADD and ADC instructions?

A

ADD: dst = dst + src
ADC: dst = dst + src + CF (Carry Flag)
ADC is used for multi-precision arithmetic.

Q

Name all 5 stages of Pentium pipeline.

A

PF → D1 → D2 → E → WB
Prefetch, Decode-1, Decode-2, Execute, Write Back

Q

What is the XLAT instruction used for?

A

Table Look-Up Translation: AL = DS:[BX + unsigned AL]
BX must point to lookup table start; AL holds index.

Q

What is speculative execution in Pentium Pro?

A

Executing instructions before knowing if they're needed (before branch outcome). Uses 40 renamed registers. Retire Unit commits results in original program order.
