# 🎓 BSc Computer Science Study Portal

A clean, academic, and visually appealing web portal designed to help BSc CS students access course materials for core subjects. Built with a focus on modern UI trends, lightweight performance, and an intuitive user experience.

## ✨ Features

*   **Modern UI/UX:** Utilizes a professional deep blue/teal color palette with premium glassmorphism effects and soft shadows.
*   **Fully Responsive:** CSS Grid and Flexbox ensure the layout looks great on both mobile devices and desktop screens.
*   **Smooth Animations:** Includes floating hero elements, subtle background grid patterns, gradient button shifts, and scroll-triggered fade-ins using the Intersection Observer API.
*   **Lightweight:** Built entirely with pure HTML, CSS, and vanilla JavaScript—no heavy frameworks required.
*   **Subject Routing:** Dedicated entry points for core courses like DBMS, Microprocessors, and Data Structures & C.

## 🛠️ Technologies Used

*   **HTML5:** Semantic structuring.
*   **CSS3:** Custom variables, flexbox/grid layouts, keyframe animations, and glassmorphism (backdrop-filter).
*   **JavaScript (ES6):** DOM manipulation and scroll animations.
*   **Font Awesome:** For scalable vector icons.
*   **Google Fonts:** Utilizing the 'Poppins' typeface for a clean, modern aesthetic.
